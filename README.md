# Udemy Kurslarım (React)

Udemy’de takip ettiğim kursları kartlar halinde listeleyen basit bir React uygulaması.


## Özellikler
- Kurs kartlarını listeleme (başlık, açıklama, fiyat, görsel)
- “Satın Almak İçin” butonu ile dış linke yönlendirme
- Hover efekti (buton üzerine gelince koyulaşır)
- Responsive tasarım (küçük ekranlarda daha düzgün görünüm)
